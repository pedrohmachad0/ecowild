# EcoWild

Jogo web 3D de exploração, ecossistema e domesticação. O protótipo jogável é a **Mata da Nascente**: cinco criaturas, IA, vínculo com a Auryn, diário, bolsa e gravação neste aparelho.

## Executar

Node.js 20.19+ ou 22.12+.

```bash
npm install
npm run dev
```

Verificação: `npm run typecheck`, `npm test`, `npm run build`.

WASD ou joystick, mouse ou arrastar para olhar, Shift corre, Espaço pula, E interage, V troca a câmera, C diário, M mapa, Esc pausa. A Auryn só aceita o vínculo depois de ser observada e de receber um frutiluz sem corrida.
