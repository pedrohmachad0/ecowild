# EcoWild

Jogo Web 3D estilizado de exploração, ecossistemas e domesticação para PC e mobile.

## Executar
Node.js 20.19+ ou 22.12+; rode `npm install`, `npm run dev`. Verificação: `npm run typecheck`, `npm test`, `npm run build`.

Protótipo técnico inicial: chão, árvores, personagem provisório, movimentação WASD, salto Espaço, câmera V/botão e joystick mobile. **Não é o MVP completo.** Controles e câmera mobile ainda exigem refinamento e testes em aparelhos reais.

**Toda IA deve começar lendo [AGENTS.md](AGENTS.md), [docs/PROJECT_SPEC.md](docs/PROJECT_SPEC.md) e [docs/ROADMAP.md](docs/ROADMAP.md).** Papéis em [agents/](agents/).
